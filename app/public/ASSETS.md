# Where the pictures come from

| file | source | note |
| --- | --- | --- |
| `duck-head-mark.webp` | pollen-robotics.com/microduck, `/assets/microduck/stickers/duck-head-mark.webp` | The site's own mark. |
| `microduck-squad.webp` | pollen-robotics.com/microduck, `/assets/microduck/squad.webp` | The four colourways — sky, graphite, cream, lavender, the charter's four shells. 1839 × 638, alpha, 146 KB, so it lands on the band's paper with no white box behind it. |
| `star-yellow.webp` | this project | The leader's star on a flyer. |

Pollen Robotics owns all three. They are copied rather than hot-linked so the
page renders the same behind any network, and so the site can be redesigned
without this one changing under it.

The site also carries `/assets/microduck/stickers/duck-head-mark-open.webp`, an
OPEN-BEAK version of the mark. The front page's quack is a tilt and a sticker
because only the closed beak was available when it was written; dropping that
file in turns it into a real two-frame alternation.
